StructuraNet AI

MY AREA · PYTHON AI ENGINE, LLM ORCHESTRATION

Describe a network in plain English and get a validated, ready-to-run GNS3 project with full Cisco IOS configurations.

  • The LLM proposes, Python decides. I separated probabilistic LLM reasoning from deterministic execution so every model output is repaired, validated, and checked before it reaches a file.
  • LLM orchestration with OpenAI function calling, replacing a rigid state machine with multi-step tool use.
  • A three-gate safe merge stops LLM-written configs from changing hardware properties set by deterministic code.
  • An 11-check structural validator inspects every exported GNS3 project archive.
  • A persistent Python worker talks to the Node.js backend over a JSONL bridge, so heavy modules load once.
PythonOpenAI function callingPydanticGNS3Cisco IOSNode.jsReact

Team of 8 at Tanta University, supervised by Assoc. Prof. Hany El-Ghaish. The thesis credits me with the Python AI engine, frontend integration, and backend support.
